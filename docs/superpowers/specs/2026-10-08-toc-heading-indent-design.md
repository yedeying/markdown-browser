# TOC 标题层级缩进设计

## 目标

仅调整右侧 `TableOfContents` 组件中的标题链接缩进，使 H1–H4 的层级结构更容易辨认，同时保持紧凑。

## 设计

- 不修改 Markdown 正文标题及其排版。
- 沿用现有 `.toc-h1` 至 `.toc-h4` 类，不改变组件结构或标题提取逻辑。
- 保留链接原有的 8px 基础左内边距，H1–H4 分别使用 `8px`、`14px`、`20px`、`26px`。
- 相邻层级递增 6px；悬停和选中背景仍覆盖完整链接行，并保留一致的左侧留白。

## 验证

- 构建客户端，确认 CSS 可正常编译。
- 检查 TOC 各层级按 6px 递增。
- 确认 Markdown 正文标题样式不受影响。
