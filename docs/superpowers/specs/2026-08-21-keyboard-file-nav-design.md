# 目录树 / 文件夹视图方向键与 hjkl 导航

## 目标

在左侧目录树有选中项，或文件夹列表/网格/列视图处于可导航选中态时，用方向键与 `hjkl` 切换文件；网格需 Enter 才打开。

## 已确认决策

| 项 | 选择 |
| --- | --- |
| 打开时机 | 树 / 列表 / 列：移动即打开（与点击同语义）；**网格：只移焦点，Enter 打开** |
| 快捷键生效 | 全局监听；焦点在 input/textarea/contenteditable/CodeMirror，或对话框/菜单/BottomSheet 打开时忽略 |
| 多选 | `selectionMode` 开启时禁用本导航 |
| 架构 | 共享工具函数 + 各视图挂监听（非 App 大一统） |

## 按键

| 键 | 树 | 列表 | 网格 | 列 |
| --- | --- | --- | --- | --- |
| `j` / ↓ | 下一可见项并打开 | 下一项并打开 | 下移焦点 | 当前列下一项（同点击） |
| `k` / ↑ | 上一可见项并打开 | 同上 | 上移焦点 | 同上 |
| `l` / → | 展开文件夹或进入 | 忽略 | 右移焦点 | 进子文件夹 / 下一列 |
| `h` / ← | 折叠或回到父 | 忽略 | 左移焦点 | 回上一列 |
| Enter | 可选（与点击同） | 可选 | **打开焦点项** | 可选 |

无当前项时：首次 `j`/`k` 选可见列表第一项（有则选并打开，网格则只设焦点）。

选中后 `scrollIntoView({ block: 'nearest' })`。

## 结构

- `src/client/utils/keyboardNav.ts`：`isTypingTarget`、键归一、可见树 DFS 扁平化、索引夹紧
- `FileTree` / `Sidebar`：树导航
- `FolderView`：按 `viewMode` 分发列表 / 网格 / 列；网格增加焦点态样式
- 打开调用现有 `onSelect` / `onFileSelect` / 列内 `handleRowClick` 语义

## 非目标

- 搜索结果列表专用导航
- 自定义快捷键配置 UI
- 多选模式下用键盘扩展选区（Shift+j 等）

## 验证

- 单测：扁平化顺序、边界、`isTypingTarget`
- E2E（可选）：树 `j` 打开下一文件；网格 `j` 不打开、Enter 打开
