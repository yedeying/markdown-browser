# 设置对话框设计

## 目标

在目录与多挂载浏览界面的右上角提供统一设置入口，让主题、氛围色、阅读排版、文件浏览、编辑器字号和启动挂载模式可配置并持久化。设置优先服务本地自用，同时保持公开、可理解、可移植。

## 入口与对话框

- 右上角操作顺序：主题、分享、设置。
- 三者统一为 32px 纯图标按钮；分享使用 `share-2`，设置使用 `sliders-horizontal`。
- 设置使用 520px 单列滚动对话框，最大高度 80vh；按“外观、阅读、文件浏览、编辑器、挂载”分组。
- 支持 Escape、遮罩点击和关闭按钮退出；交互元素沿用全局 accent 焦点样式。
- 分享仅在当前对象可分享时显示，设置始终显示；单文件预览只保留主题，不提供目录类设置。

## 设置项

除挂载模式外均即时生效并写入 localStorage：

| 分组 | 设置 | 值 |
| --- | --- | --- |
| 外观 | 主题 | 深色、浅色、跟随系统 |
| 外观 | 氛围色 | 橙、蓝、青、绿、紫、玫红、自定义 |
| 阅读 | 内容宽度 | 720、900、1140、不限 |
| 阅读 | 正文字号 | 14、15、16、17px |
| 阅读 | 行高 | 1.55、1.7、1.9 |
| 文件浏览 | 默认视图 | 列表、网格、分栏 |
| 文件浏览 | 默认排序 | 名称、类型、大小；升序、降序 |
| 文件浏览 | 显示隐藏文件 | 关闭、开启 |
| 编辑器 | 字号 | 13、14、15px |

首批不提供编辑器自动换行开关。当前 CodeMirror 将 `EditorView.lineWrapping` 固定为扩展，关闭它需要动态重配置，而需求收益不足。

底部提供“重置本地偏好”，二次确认后只删除 `vmd_*` localStorage 项并刷新页面，不删除服务端配置和会话滚动位置。

## 偏好同步

`prefs.ts` 作为本地偏好唯一入口：

- 提供类型化默认值、读写函数和订阅机制。
- 同页组件通过订阅收到更新，设置对话框修改默认视图、排序或隐藏文件时无需刷新。
- 阅读和编辑器设置映射到根节点 CSS 变量。
- 页面渲染前在 `main.tsx` 应用主题、氛围色和排版变量，避免首帧闪烁。

主题新增 `system` 值。系统主题变化时，只有选择“跟随系统”的用户会实时同步实际主题。

## 氛围色

六个预设各保存深、浅主题色值。自定义色在深色主题直接使用；浅色主题将其与黑色混合以保证对比。根据相对亮度自动选择 `--on-accent` 为白色或近黑色。

覆盖 `--accent`、`--accent-active`、`--on-accent`；现有 `--accent-soft`、`--accent-faint`、`--focus-glow` 继续由 CSS `color-mix()` 自动衍生。

## 启动挂载模式

`.vmd-config.json` 扩展为：

```json
{
  "startupMode": "multi",
  "singleMountAlias": "notes",
  "mounts": []
}
```

- 目录模式切多挂载：以当前目录作为 workspace，并自动登记为首个挂载点；保存 `startupMode: "multi"`。
- 多挂载切单挂载：从已有挂载点选择目标，保存 `startupMode: "dir"` 和 `singleMountAlias`。
- 保存成功后提示“重启服务后生效”，当前进程不热切换根目录。
- CLI 启动时读取当前目录或 workspace 下的 `.vmd-config.json`，让已保存的启动模式覆盖路径参数的默认推断。
- 命令行显式 `--mount` 仍合并进配置；无效或不存在的单挂载目标回退到命令行推断并输出警告。
- 管理接口继续位于现有 `/api/admin/*` 路由下，复用父应用鉴权中间件。

## 验证

- 单元测试覆盖偏好读写/订阅、accent 派生、配置模式解析和持久化。
- Playwright 覆盖设置入口、Escape 关闭、即时主题/氛围色/阅读设置、隐藏文件联动及重置确认。
- 构建与现有单元、E2E 测试必须通过；记录已知的既有 flaky 测试，不将其误报为本功能回归。
