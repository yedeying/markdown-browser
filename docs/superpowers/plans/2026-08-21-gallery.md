# Gallery (Masonry + Lightbox) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dynamic「瀑布流」folder view and a shared media Lightbox with left/right browsing across list/grid/column/masonry.

**Architecture:** Pure helpers for media detection/filtering/playlist; `MediaLightbox` overlay owned by `FolderView` (and reused from ContentArea for deep links); `FolderMasonryView` mirrors grid keyboard/selection patterns; prefs gain `masonry`.

**Tech Stack:** Preact 10, existing `getFileType` / `assetUrl` / `usePref`, CSS columns or CSS grid masonry, bun:test + Playwright e2e.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-21-gallery-design.md`
- Masonry button only when visible children include image **or** video
- Masonry shows folders + media only (hide other files)
- List/grid/column layouts unchanged; opening image/video → Lightbox
- No server thumbnails, no auto-switch into masonry, no filmstrip mode
- Lightbox blocks folder/tree keyboard nav via overlay selector
